# SK-DA-19

> Draws a bar graph of a data set from a table, with a scale the learner chooses.

Authored by ConveGenius. Belongs to [[LO-M819 Draws and interprets bar charts and pie charts]].

| Field | Content |
|---|---|
| Action | draws |
| Content | a bar graph of one data set |
| Conditions | table of 4 to 8 categories with whole-number values from 5 to 500; categories such as sports, months, subjects, years; graph paper; scale chosen by the learner; bars of equal width with equal gaps; both axes labelled and the graph titled |
| Role | outcome task |
| Example task | The table shows the number of Class 8 students whose favourite sport is Cricket 45, Football 30, Hockey 15, Kabaddi 20, Kho-kho 10. Draw a bar graph on graph paper, choosing a scale. |

| Stopping rule | Marking the axes, drawing each bar to its length and labelling are done together in every graph and cannot be evidenced apart; choosing the scale is split off as SK-DA-21. |
