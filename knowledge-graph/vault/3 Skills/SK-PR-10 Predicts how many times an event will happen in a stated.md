# SK-PR-10

> Predicts how many times an event will happen in a stated number of further trials, using the chance found from earlier trials.

Authored by ConveGenius. Belongs to [[LO-M820 Makes hypotheses on chances of future events on the]].

| Field | Content |
|---|---|
| Action | predicts |
| Content | the number of times an event happens in further trials |
| Conditions | earlier results of 20 to 200 trials given in a table or list (coin, die, spinner, or a daily-life record); further trials from 100 to 1000, chosen so that the expected number is a whole number; answer written as 'about N times' |
| Role | outcome task |
| Example task | In 50 tosses of a coin, heads came up 21 times. Using this record, how many heads do you expect in 200 more tosses? |
