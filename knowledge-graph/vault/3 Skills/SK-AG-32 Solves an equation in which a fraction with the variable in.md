# SK-AG-32

> Solves an equation in which a fraction with the variable in its numerator and denominator equals a number or another fraction, reducing it to a linear equation.

Authored by ConveGenius. Belongs to [[LO-M806 Solves puzzles and daily life problems using variables]].

| Field | Content |
|---|---|
| Action | solves |
| Content | an equation with the variable in the numerator and denominator of a fraction |
| Conditions | forms (ax + b)/(cx + d) = p/q and (ax + b)/(cx) = p, with a, b, c, d, p and q integers from −20 to 20; solution an integer or a fraction with denominator up to 10, possibly negative, that does not make a denominator zero; written working; solution stated as x = … |
| Role | step; carried out inside [[SK-AG-28 Solves a word problem by writing and solving a linear]] (sometimes) |
| Example task | Solve (x + 1)/(2x + 3) = 3/8.   Solve (7y + 4)/(y + 2) = −4/3. |
