# SK-RN-38

> States in words or with letters the general property shown by a set of worked examples with rational numbers.

Authored by ConveGenius. Belongs to [[LO-M801 Generalises properties of addition, subtraction,]].

| Field | Content |
|---|---|
| Action | states |
| Content | a general property from examples |
| Conditions | three to five worked examples given; properties: closure, commutativity, associativity, identity, inverse, distributivity |
| Role | outcome task |
| Example task | (-2/3) + 1/5 = 1/5 + (-2/3); 3/4 + (-1/2) = (-1/2) + 3/4; ... What is true in general? |
