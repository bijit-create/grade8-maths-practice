# SK-NN-02

> Finds the cube of an integer.

Authored by ConveGenius. Belongs to [[LO-M804 Finds squares, cubes and square roots and cube roots]].

| Field | Content |
|---|---|
| Action | finds |
| Content | the cube of an integer |
| Conditions | integers from -10 to 10; a negative base written in brackets; given in index form, as in 4³, or in words; written symbols |
| Role | outcome task; carried out inside [[SK-NN-03 Identifies whether a given whole number is a square number,]] (sometimes), [[SK-NN-05 Finds the cube root of a cube number]] (sometimes) |
| Example task | 4³ = ?   (-2)³ = ? |

| Test | Result |

| Separation | Pass against [[SK-NN-01 Finds the square of an integer]]. A learner gives 5² = 25 and (-6)² = 36 but 5³ = 15, multiplying the base by the index. |
