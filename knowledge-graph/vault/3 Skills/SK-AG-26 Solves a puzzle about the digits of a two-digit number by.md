# SK-AG-26

> Solves a puzzle about the digits of a two-digit number by writing and solving a linear equation in one variable.

Authored by ConveGenius. Belongs to [[LO-M806 Solves puzzles and daily life problems using variables]].

| Field | Content |
|---|---|
| Action | solves |
| Content | a puzzle about the digits of a two-digit number and the number made by interchanging them |
| Conditions | two-digit numbers; the puzzle gives the sum or the difference of the digits, or one digit as a multiple of the other, and the sum or the difference of the number and the number made by interchanging the digits; one unknown digit, the other digit written from it; the equation is not given and may have the variable on one or both sides; answer is the number, checked against the puzzle |
| Role | outcome task |
| Example task | The sum of the digits of a two-digit number is 9. When the digits are interchanged, the new number is 27 greater than the original number. Find the number. |

## Grain tests (V2 §3.2)

| Test | Result |
|---|---|
| Statement | Pass: one principal verb. |
| Task | Pass: the example task produces evidence of this skill. |
| Separation | Pass against [[SK-AG-25 Solves a word problem about numbers, ages, money or]]. A learner solves 'the sum of three consecutive multiples of 8 is 888' correctly as 288, 296 and 304, but for 'the digits of a two-digit number add up to 9' writes the number as x + (9 − x) and the number with its digits interchanged as (9 − x) + x, adding the digits instead of using their place values. |
| Stopping rule | Writing the number from its digits and solving the equation are done together; the textbook gives digit puzzles one set of worked examples, and the stated range keeps them to two-digit numbers. |
