# SK-AG-30

> Solves a linear equation in one variable that has the variable on both sides or inside a bracket.

Authored by ConveGenius. Belongs to [[LO-M806 Solves puzzles and daily life problems using variables]].

| Field | Content |
|---|---|
| Action | solves |
| Content | a linear equation with variable terms on both sides |
| Conditions | forms ax + b = cx + d, a(x + b) = cx + d and a(x + b) = c(x + d); integer coefficients from −20 to 20; solution an integer or a fraction with denominator up to 10, possibly negative; written working; solution stated as x = … |
| Role | step; carried out inside [[SK-AG-27 Solves a word problem by writing and solving a linear]] (always), [[SK-AG-26 Solves a puzzle about the digits of a two-digit number by]] (sometimes), [[SK-AG-31 Solves a linear equation in one variable that has fractions]] (always), [[SK-AG-32 Solves an equation in which a fraction with the variable in]] (always) |
| Example task | Solve 5x − 7 = 2x + 8.   Solve 3(x − 4) = x + 6. |
