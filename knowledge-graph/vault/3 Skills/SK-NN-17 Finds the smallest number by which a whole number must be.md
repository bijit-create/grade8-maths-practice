# SK-NN-17

> Finds the smallest number by which a whole number must be multiplied, or divided, to make a perfect cube.

Authored by ConveGenius. Belongs to [[LO-M804 Finds squares, cubes and square roots and cube roots]].

| Field | Content |
|---|---|
| Action | finds |
| Content | the smallest multiplier or divisor that makes a perfect cube |
| Conditions | whole numbers from 20 to 99 999 that are not perfect cubes, with prime factors all less than 20; by prime factorisation; the direction (multiply or divide) stated in the task; answer one whole number |
| Role | outcome task |
| Example task | Find the smallest number by which 392 must be multiplied to make a perfect cube. Find the smallest number by which 53240 must be divided to make a perfect cube. |

| Stopping rule | Both directions use the incomplete triples, so they are one procedure; splitting them gives parts that cannot be evidenced apart. |
