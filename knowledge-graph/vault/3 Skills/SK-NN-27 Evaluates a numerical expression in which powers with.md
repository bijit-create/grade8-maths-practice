# SK-NN-27

> Evaluates a numerical expression in which powers with negative integer exponents are combined by addition, subtraction, multiplication or division.

Authored by ConveGenius. Belongs to [[LO-M805 Solves problems with integral exponents]].

| Field | Content |
|---|---|
| Action | evaluates |
| Content | an expression of powers with negative exponents combined by operations |
| Conditions | bases whole numbers from 2 to 10 or unit fractions 1/2 to 1/5; exponents from -3 to 3 including 0; up to three powers in one expression, with at most one bracket; answer an integer or a fraction with denominator up to 100; written symbols |
| Role | outcome task |
| Example task | Find the value of (3^0 + 4^(−1)) × 2^2.   Find the value of (1/2)^(−1) + (1/3)^(−1) + (1/4)^(−1).   Find the value of ((1/3)^(−1) − (1/4)^(−1))^(−1). |
