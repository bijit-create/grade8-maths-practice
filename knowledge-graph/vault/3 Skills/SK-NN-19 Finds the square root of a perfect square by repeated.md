# SK-NN-19

> Finds the square root of a perfect square by repeated subtraction of successive odd numbers.

Authored by ConveGenius. Belongs to [[LO-M804 Finds squares, cubes and square roots and cube roots]].

| Field | Content |
|---|---|
| Action | finds |
| Content | the square root of a perfect square |
| Conditions | perfect squares from 1 to 400; subtracting 1, 3, 5, … in order until 0 is reached; written working; answer the number of subtractions |
| Role | outcome task |
| Example task | Find the square root of 169 by repeated subtraction of successive odd numbers. |
