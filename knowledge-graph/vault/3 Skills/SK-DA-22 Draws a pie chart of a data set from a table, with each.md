# SK-DA-22

> Draws a pie chart of a data set from a table, with each sector drawn to its central angle using a protractor.

Authored by ConveGenius. Belongs to [[LO-M819 Draws and interprets bar charts and pie charts]].

| Field | Content |
|---|---|
| Action | draws |
| Content | a pie chart of one data set |
| Conditions | table of 3 to 6 categories with whole-number values whose total divides 360 (such as 12, 24, 30, 36, 40, 60, 72, 90), or with percentages that give whole-number central angles; contexts such as hours in a day, favourite colours, modes of travel to school; circle drawn with compasses, radius 4 to 6 cm, on plain paper; sectors labelled |
| Role | outcome task |
| Example task | Priya spends the 24 hours of a day as follows: sleep 8, school 6, homework 4, play 2, other 4. Draw a pie chart. |

## Grain tests (V2 §3.2)

| Test | Result |
|---|---|
| Statement | Pass: one principal verb. |
| Task | Pass: the example task produces evidence of this skill. |
| Separation | Pass against [[SK-DA-23 Finds the central angle of each sector of a pie chart from]]. A learner finds the angles 120°, 90°, 60°, 30° and 60° for Priya's day correctly but measures every angle from the same horizontal line, so the sectors overlap and part of the circle is left empty. |
| Stopping rule | Drawing the circle, marking each sector from the end of the one before and labelling are done together in every chart; finding the angles is split off as SK-DA-23. |
