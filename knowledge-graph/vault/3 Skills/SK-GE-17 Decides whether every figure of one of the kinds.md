# SK-GE-17

> Decides whether every figure of one of the kinds parallelogram, rhombus, rectangle and square is also a figure of another of these kinds, giving the reason.

Authored by ConveGenius. Belongs to [[LO-M812 Verifies properties of parallelograms and establishes]].

| Field | Content |
|---|---|
| Action | decides |
| Content | whether one kind of quadrilateral is a special case of another, from their definitions |
| Conditions | pairs taken from parallelogram, rhombus, rectangle and square; statement of the form 'Every X is a Y'; response: true or false with a reason from the definitions, and for a false statement a figure of kind X that is not of kind Y described |
| Role | outcome task |
| Example task | Is every rectangle a square? Is every square a rectangle? Give a reason for each. |

## Grain tests (V2 §3.2)

| Test | Result |
|---|---|
| Statement | Pass: one principal verb. |
| Task | Pass: the example task produces evidence of this skill. |
| Separation | Pass against [[SK-GE-18 Identifies which of the parallelogram, rhombus, rectangle]]. A learner decides correctly that 'every rectangle is a square' is false and 'every square is a rectangle' is true, but asked which of the four kinds have four equal sides lists only the rhombus. |
| Stopping rule | Comparing the definitions of two kinds and stating whether the first is included in the second is one act; no smaller task shows the relationship. |
