# SK-GE-18

> Identifies which of the parallelogram, rhombus, rectangle and square have a stated property.

Authored by ConveGenius. Belongs to [[LO-M812 Verifies properties of parallelograms and establishes]].

| Field | Content |
|---|---|
| Action | identifies |
| Content | the kinds of quadrilateral, among parallelogram, rhombus, rectangle and square, that have a given property |
| Conditions | properties: opposite sides parallel, four equal sides, four right angles, equal diagonals, diagonals that meet at right angles, diagonals that bisect each other; response: the list of all the kinds that have the property |
| Role | outcome task |
| Example task | Which of the parallelogram, rhombus, rectangle and square have diagonals that are equal in length? |

## Grain tests (V2 §3.2)

| Test | Result |
|---|---|
| Statement | Pass: one principal verb. |
| Task | Pass: the example task produces evidence of this skill. |
| Separation | Pass against [[SK-GE-17 Decides whether every figure of one of the kinds]]. A learner lists the rhombus and the square for four equal sides and the rectangle and the square for four right angles, but decides that 'every parallelogram is a rectangle' is true because every rectangle is a parallelogram. |
| Stopping rule | Checking each of the four kinds against the property is one act; the list is the evidence and no smaller task can be set. |
