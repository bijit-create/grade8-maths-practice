# SK-NN-03

> Identifies whether a given whole number is a square number, a cube number, both or neither.

Authored by ConveGenius. Belongs to [[LO-M804 Finds squares, cubes and square roots and cube roots]].

| Field | Content |
|---|---|
| Action | identifies |
| Content | square numbers and cube numbers |
| Conditions | whole numbers from 1 to 1000; square numbers up to 15² = 225 and cube numbers up to 10³ = 1000; response by sorting, circling or writing the class |
| Role | outcome task |
| Example task | Which of 27, 36, 50, 64 and 125 are square numbers, which are cube numbers, and which are both? |
