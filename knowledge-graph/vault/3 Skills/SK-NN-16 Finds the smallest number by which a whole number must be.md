# SK-NN-16

> Finds the smallest number by which a whole number must be multiplied, or divided, to make a perfect square.

Authored by ConveGenius. Belongs to [[LO-M804 Finds squares, cubes and square roots and cube roots]].

| Field | Content |
|---|---|
| Action | finds |
| Content | the smallest multiplier or divisor that makes a perfect square |
| Conditions | whole numbers from 12 to 9999 that are not perfect squares, with prime factors all less than 20; by prime factorisation; the direction (multiply or divide) stated in the task; answer one whole number |
| Role | outcome task |
| Example task | Find the smallest number by which 252 must be multiplied to make a perfect square. Find the smallest number by which 9408 must be divided to make a perfect square. |
