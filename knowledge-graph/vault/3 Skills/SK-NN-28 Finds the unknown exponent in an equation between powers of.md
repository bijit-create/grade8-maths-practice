# SK-NN-28

> Finds the unknown exponent in an equation between powers of the same base, using the laws of exponents.

Authored by ConveGenius. Belongs to [[LO-M805 Solves problems with integral exponents]].

| Field | Content |
|---|---|
| Action | finds |
| Content | the unknown exponent m |
| Conditions | one base, an integer other than 0, 1 and -1 or a fraction; the unknown appears in one exponent only, as m, m + 1 or 2m − 1; powers combined by × or ÷; integer solution from -10 to 10; written working |
| Role | outcome task |
| Example task | Find m so that (−3)^(m + 1) × (−3)^5 = (−3)^7.   Find m so that 5^m ÷ 5^(−3) = 5^5.   Find m so that (2/9)^3 × (2/9)^(−6) = (2/9)^(2m − 1). |
