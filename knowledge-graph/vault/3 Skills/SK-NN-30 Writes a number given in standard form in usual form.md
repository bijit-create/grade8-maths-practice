# SK-NN-30

> Writes a number given in standard form in usual form.

Authored by ConveGenius. Belongs to [[LO-M805 Solves problems with integral exponents]].

| Field | Content |
|---|---|
| Action | writes |
| Content | a × 10^n as a decimal or whole number |
| Conditions | a × 10^n with a a decimal from 1 to 9.999 with up to four digits and n an integer from -20 to 15; answer a decimal or whole number written out; written symbols |
| Role | outcome task |
| Example task | Write 3.5 × 10^(−3) and 1.496 × 10^11 in usual form. |
