# KI-NN-37

> To find the smallest number by which a number must be divided to make a perfect cube, write its prime factorisation, group equal primes in triples, and divide by the product of the primes left over; to find the smallest number by which it must be multiplied, multiply by the primes needed to complete each incomplete triple.
