# KI-PR-20

> When an experiment is repeated in the same way, the experimental probability of an event from earlier trials is an estimate of the probability that the event happens in a further trial, and the estimate is better the more earlier trials there are.

Kind: Principle. Where required, it is required **before attainment**. With rationale. First expected in Grade 8.

**Note.** Authored for the reading of M820 used here (a hypothesis about a future event from earlier occurrences); the Class 8 chapter does not state it in these words.

Required by skills in grade(s): 8.
