# Error layer

One note per known wrong answer (error pattern), hung under the skill whose task produced it. Every pattern and every cause says where it came from and whether it has been observed. Nothing here is trusted until it is observed in learner data.

To hide this layer in Obsidian's graph view, add `-path:"7 Error layer"` to the graph filter.

## How a wrong answer flows

1. A learner gives a wrong answer on a skill's attainment check.
2. It is matched to an error pattern under that skill, or recorded as a new one.
3. The pattern's possible causes are listed; each points at a knowledge item, a step skill, or a contrast pair in the graph.
4. Probes run until one cause is left.
5. The surviving cause decides what PAL teaches next, following the link it points to.
